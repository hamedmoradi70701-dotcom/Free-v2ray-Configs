    常见问题

    免费 V2Ray 配置：本项目如何运作

    什么是 Free-v2ray-Configs？

    一个开源的 V2Ray / Xray 配置集合（VLESS、Reality、VMess、Trojan、Shadowsocks、Hysteria2），由 0xRadikal 以 رادار 品牌维护。它大约每 15 分钟在 GitHub Actions 上重建一次，并发布纯文本、Base64、Clash 和 sing-box 订阅。

    我应该用哪个列表？

    从“已验证”开始。“快速”是中位延迟低于阈值的已验证配置，“安全”只保留启用了前向保密和证书校验的已验证配置。All / Heavy / Light 池大得多，但大多未经测试。

    配置是如何验证的？

    每个配置都会被拨号连接，然后用它向 cp.cloudflare.com/generate_204 发出真实 HTTP 请求。只有在本构建全部 3 个独立轮次中都成功的配置才能进入已验证列表。仅有 TCP 连接是不够的。

    我的应用需要哪种格式？

    Base64 是经典订阅，也是最安全的默认选择（v2rayNG、v2rayN、Hiddify、Streisand、Shadowrocket）。纯文本是同一列表的未编码版本。clash.yaml 是完整的 mihomo / Clash Meta 配置文件，singbox.json 是完整的 sing-box 配置。

    这些配置能在我的网络上用吗？

    不一定。测试从本页显示的运行节点位置进行。过滤因国家和 ISP 而异，因此已验证的配置只能证明它在测试地可用，并不代表在所有地方都可用。

    安全吗？服务器能看到我的流量吗？

    服务器运营者可以看到你的 IP 和连接元数据，以及任何未端到端加密的流量。请使用 HTTPS，优先选择“安全”列表，切勿将这些配置用于敏感账户。本项目不对任何运营者做担保。

    Radar 电报机器人 是什么？

    رادار 的 Telegram 机器人（v2Ray Extractor）。它已连接到本仓库，在 Telegram 内免费发放配置，你无需访问网站。
