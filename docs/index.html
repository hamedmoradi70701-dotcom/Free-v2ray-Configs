    QUESTIONS

    Free V2Ray configs: how this project works

    What is Free-v2ray-Configs?

    An open-source collection of V2Ray / Xray configs (VLESS, Reality, VMess, Trojan, Shadowsocks, Hysteria2) maintained by 0xRadikal under the رادار brand. It rebuilds about every 15 minutes on GitHub Actions and publishes plain, Base64, Clash and sing-box subscriptions.

    Which list should I use?

    Start with Verified. Fast is the verified configs whose median delay was under the threshold, and Secure keeps only verified configs with forward secrecy and certificate validation left on. The All / Heavy / Light pools are much larger but mostly untested.

    How is a config verified?

    Each config is dialled and then used to make a real HTTP request to cp.cloudflare.com/generate_204. Only configs that succeed in all 3 independent rounds of the build reach the verified list. A TCP connection alone is not enough.

    Which format does my app need?

    Base64 is the classic subscription and the safest default (v2rayNG, v2rayN, Hiddify, Streisand, Shadowrocket). Plain text is the same list unencoded. clash.yaml is a full mihomo / Clash Meta profile, and singbox.json is a full sing-box config.

    Will these configs work on my network?

    Not necessarily. Tests run from the runner location shown on this page. Filtering differs by country and ISP, so a verified config proves it works from there, not from everywhere.

    Is it safe? Can the server see my traffic?

    The server operator can see your IP and connection metadata, and any traffic that is not encrypted end to end. Use HTTPS, prefer the Secure list, and never use these for sensitive accounts. This project does not certify any operator.
