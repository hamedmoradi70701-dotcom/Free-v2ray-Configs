    ВОПРОСЫ

    Бесплатные конфиги V2Ray: как работает этот проект

    Что такое Free-v2ray-Configs?

    Коллекция конфигов V2Ray / Xray с открытым кодом (VLESS, Reality, VMess, Trojan, Shadowsocks, Hysteria2), которую ведёт 0xRadikal под брендом رادار. Она пересобирается примерно каждые 15 минут на GitHub Actions и публикует подписки в форматах обычного текста, Base64, Clash и sing-box.

    Какой список мне использовать?

    Начните с «Проверенных». «Быстрые» — это проверенные конфиги, чья медианная задержка оказалась ниже порога, а «Безопасные» оставляют только проверенные конфиги с включённой прямой секретностью и проверкой сертификатов. Пулы All / Heavy / Light намного больше, но в основном не протестированы.

    Как проверяется конфиг?

    Каждый конфиг подключается, а затем через него выполняется реальный HTTP-запрос к cp.cloudflare.com/generate_204. В проверенный список попадают только конфиги, успешные во всех 3 независимых раундах сборки. Одного TCP-подключения недостаточно.

    Какой формат нужен моему приложению?

    Base64 — классическая подписка и самый безопасный вариант по умолчанию (v2rayNG, v2rayN, Hiddify, Streisand, Shadowrocket). Обычный текст — тот же список без кодирования. clash.yaml — полный профиль mihomo / Clash Meta, а singbox.json — полная конфигурация sing-box.

    Будут ли эти конфиги работать в моей сети?

    Не обязательно. Тесты выполняются из места расположения раннера, указанного на этой странице. Фильтрация различается по странам и провайдерам, поэтому проверенный конфиг доказывает работоспособность оттуда, а не отовсюду.

    Это безопасно? Видит ли сервер мой трафик?

    Оператор сервера может видеть ваш IP и метаданные подключения, а также любой трафик, не зашифрованный сквозным шифрованием. Используйте HTTPS, предпочитайте список «Безопасные» и никогда не используйте эти конфиги для чувствительных аккаунтов. Этот проект не сертифицирует ни одного оператора.
